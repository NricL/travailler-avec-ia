# Travailler avec l’IA

Site autonome consacré à la masterclass « Travailler avec l’IA. Progresser dans son métier. »

## Contenu

- `index.html` : parcours de lecture, trois situations professionnelles et mode « Animer ».
- `masterclass-illustrations/` : les 14 illustrations utilisées par la page.
- `assets/iaetjob-qr.svg` : le QR code affiché après la synthèse finale, vers `https://aka.ms/iaetjob`.
- La section `#formations`, après la conclusion du site, regroupe six ressources en deux axes : maîtrise de l’IA et compétences pour le premier emploi. Elle reste hors du mode Animation. Les liens LinkedIn fournis ouvrent le catalogue, ce qui est indiqué au lecteur.

Le site est statique et ne nécessite ni compilation ni dépendances d’exécution. Les textes développés, la partie 3 et la conclusion validée sont conservés dans le parcours. En mode présentation, un clic sur la diapositive ou les flèches permettent d’avancer ; les illustrations précèdent leurs messages, affichés ensemble. Les parties 1 et 2 ont un écran titre, la synthèse présente ses messages en rappel latéral, puis le QR code termine la projection.

## Publication

Le site est publié indépendamment de MyPage avec GitHub Pages, depuis la branche `main` via le workflow `.github/workflows/pages.yml`.
