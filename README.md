# Travailler avec l’IA

Site autonome consacré à la masterclass « Travailler avec l’IA. Transformer le travail. »

## Contenu

- `index.html` : parcours de lecture, trois situations professionnelles et mode « Animer ».
- `masterclass-illustrations/` : les 14 illustrations utilisées par la page.

Le site est statique et ne nécessite ni compilation ni dépendances. Les textes développés, la partie 3 et la conclusion validée sont conservés dans le parcours. La projection garde une seule séquence pour l’illustration 08 et révèle les messages de conclusion progressivement.

## Publication

Le site est publié indépendamment de MyPage avec GitHub Pages, depuis la branche `main` via le workflow `.github/workflows/pages.yml`.
